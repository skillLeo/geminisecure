Settings: estate profile, users & roles, feature toggles & role access matrix

The complete Settings section in one place — Document 05 §2.4's four core Settings screens: the estate's own profile and branding, the users & roles list, the feature toggle panel (every optional module as a switch, gated by subscription tier per Document 13), and the role access matrix using the exact seven roles from Document 05 §2.3: Super Admin, President, Vice President, Secretary, Property Manager, Treasurer, and Admin Assistant. Same desktop shell and Bright Navy Blue / white / amber palette as the rest of the Estate Console.

Guards are Gemini Security Limited's own employees. This console has no Access & Security module and no security-guard payroll anywhere — rostering, standing orders, live gate monitoring, and guard pay are all managed centrally in the Gemini Console. The Payroll routing row below reflects that split: "In-house" is selected for the estate's own staff (Patricia Morgan and team); the Treasurer's Full access to Payroll & HR in the role matrix covers only that same staff.
