The locked style guide

Every token, type size, radius, shadow and component below is transcribed verbatim from the approved wireframe set — Poppins for display, Inter for interface, navy for structure, amber for emphasis. Nothing here is an interpretation. The three product surfaces (Gemini Console, Resident App, Guard App) all resolve from this one sheet, so a value changed here changes everywhere and a value invented anywhere else is a defect.
